Installing

Windows

Run Aether-Setup.exe. If Windows SmartScreen says it “protected your PC”, choose More info → Run anyway (the app isn't code-signed yet). Aether updates itself from then on.

macOS

Open the .dmg and drag Aether into Applications. The first time, right-click Aether → Open, then Open again: the build isn't notarised by Apple yet, so a normal double-click is blocked once.

Linux

For the AppImage, make it executable (chmod +x Aether_*_linux-x86_64.AppImage) and run it. On Debian or Ubuntu you can install the .deb instead: sudo apt install ./Aether_*_linux-amd64.deb.

Android

Download the APK and open it. Android asks you to allow installs from your browser once. The app then offers updates itself.

iPhone and iPad

Aether isn't on the App Store yet. Install the .ipa with SideStore, AltStore or Sideloadly. With a free Apple account you'll need to refresh it every 7 days. Or add the web app to your Home Screen: Share → Add to Home Screen.

In your browser

Everything works at joinaether.vercel.app/app in Chrome, Edge, Firefox and Safari, with nothing to install.
